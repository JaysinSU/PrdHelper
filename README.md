# Base PRD Helper

用于飞书多维表格 Base 的需求梳理、方案讨论、PRD 起草、评审和局部修订。调用名为 `$prd-helper`。

| 内容 | 适用场景 |
| --- | --- |
| 追加导入 Excel | 判断追加还是合并，设计字段映射、预览、失败恢复与重试 |
| 数据表和视图描述 | 明确对象归属、入口、角色权限、保存状态与复制 |
| 富文本字段 | 拆分值与摘要，定义转换结果、跨视图展示、分享和编辑 |
| 交付方法 | 按阶段写 PRD，核对证据、正文、线稿、验收、发布和埋点 |

将仓库内容放入 `~/.codex/skills/prd-helper/`，确保 `SKILL.md`、`references/` 和 `agents/` 在同一个技能目录。使用自定义 Codex 目录时，将技能放入对应的 `skills` 子目录。已有同名技能时先比较版本。重新加载技能后可尝试以下请求。

> 用 $prd-helper 评审 Excel 追加导入方案，重点检查字段映射、部分写入和失败重试。

主入口见 [SKILL.md](SKILL.md)。按需使用飞书文档、Base 或画板工具，具体可用性取决于运行环境。案例以合成数据说明方法，实际规则以本次需求确认和实测为准。
